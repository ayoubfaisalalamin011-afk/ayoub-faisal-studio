# Ayoub Faisal Studio

Create a premium, modern, fully responsive personal portfolio website for AYOUB FAISAL.

Use an elegant editorial design inspired by high-end creative studios and award-winning portfolio websites. The visual identity should use forest green (#183D2B), deep green (#24563D), sage (#DCE7D8), and warm ivory (#F4F3ED).

The website should feel custom-designed, sophisticated, and professional — never like a generic AI template.

Start with a striking animated typographic intro featuring “AYOUB FAISAL.” Then create a beautiful homepage with a strong hero section, smooth scroll animations, elegant transitions, refined hover effects, and a floating modern navigation bar.

Hero headline: “Building digital experiences with purpose.”

Add two hero buttons: “Explore My Work” and “Let’s Talk”.

Build these sections in order:

Animated introduction.

Hero section.

Selected Projects.

About Me.

Services.

Contact section.

Minimal elegant footer.

Use clean typography, generous whitespace, beautiful layouts, subtle textures, carefully balanced colors, and polished micro-interactions. Make the design visually impressive on desktop and mobile.

The website must support English by default and Arabic through a language toggle. Arabic must use proper right-to-left layout.

Make all navigation links and buttons functional. Use accessible semantic HTML, responsive layouts, optimized animations, and respect reduced-motion preferences. Use a custom cursor only on desktop devices.

For now, focus on creating the overall visual foundation, homepage structure, navigation, responsive layout, and design system. Do not invent project screenshots or add fake projects. We will add the real portfolio projects and remaining functionality in later stages.

Build a real working website, not just a static mockup.
